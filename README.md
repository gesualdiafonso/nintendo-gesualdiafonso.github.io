# 🎮 Nintendo Switch Copy – Responsive UI Design Challenge

This is a **fully responsive front-end project** inspired by the official **Nintendo Switch** website, created as an academic assignment for the course **IDM – Interaction with Mobile Devices**.

The challenge focused on building a pixel-precise replica of a real product site with high fidelity, adapting across all screen sizes—from mobile (420px) to full desktop (1920px). The project showcases front-end development skills in creating responsive layouts, adaptive navigation, and fluid design systems.

## 🌐 Live Preview

👉 https://nintendoswitch.vercel.app

---

## 📱 Project Goals

- Recreate a real-world digital product layout (Nintendo Switch)
- Design fluid breakpoints between **420px and 1920px**
- Implement a **sidebar menu** for smaller devices
- Show a **navbar** for larger screens (e.g. desktops and tablets)
- Deliver a **pixel-consistent user interface** regardless of device type
- Practice responsive and mobile-first development

---

## 🛠️ Tech Stack

- **HTML5** – Semantic and clean structure  
- **CSS3** – Custom styling and media queries for responsiveness  
- **JavaScript (Vanilla)** – DOM manipulation and interactive sidebar logic  

---

## 📐 Responsive Design Highlights

- **Mobile Devices (420px+)**  
  - Sidebar navigation for minimal UI
  - Focus on stacking content vertically
  - Optimized touch zones

- **Tablets to Desktop (768px–1920px)**  
  - Horizontal layout with clear content zoning
  - Navbar becomes persistent
  - Scalable typography and fluid grid

- **Consistent Breakpoints**  
  The layout adapts seamlessly across screen widths with no visual distortion.
